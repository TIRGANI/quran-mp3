# القرآن الكريم — Ali Jaber

Application web pour écouter les 114 sourates du Saint Coran, récitation **Ali Jaber**, même sans connexion.

- Recherche (nom, traduction, numéro) et filtres Mecquoises / Médinoises
- Écoute hors connexion : le Juz ‘Amma est gardé à la première visite, ainsi que chaque sourate écoutée ;
  bouton ↓ par sourate ou « Tout télécharger »
- Installable comme une application (PWA) sur téléphone et ordinateur

L'audio est servi par [mp3quran.net](https://mp3quran.net).
