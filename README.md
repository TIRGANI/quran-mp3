# القرآن الكريم — Coran MP3

Application web pour écouter les 114 sourates du Saint Coran, au choix parmi **64 récitateurs** (lectures Hafs et Warsh), même sans connexion.

- Choix du récitateur (carrousel illustré, recherche, lecture Hafs/Warsh)
- Recherche (nom, traduction, numéro) et filtres Mecquoises / Médinoises
- Écoute hors connexion : le Juz ‘Amma est gardé à la première visite, ainsi que chaque sourate écoutée ;
  bouton ↓ par sourate ou « Tout télécharger »
- Installable comme une application (PWA) sur téléphone et ordinateur, ou via l'APK Android

L'audio est servi par [mp3quran.net](https://mp3quran.net). Les photos des récitateurs viennent de [surahquran.com](https://surahquran.com).
